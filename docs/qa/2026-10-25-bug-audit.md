## পরীক্ষার সীমা ও deployment-এর আগে করণীয়

Physical Android/iPhone microphone, বাংলা কণ্ঠের বাস্তব acoustic accuracy, device permission prompts, installed APK version এবং real PostgreSQL restart durability এই local memory audit-এ যাচাই হয়নি। Recording lifecycle browser regressions-এ simulated recorder দিয়ে পরীক্ষা করা হয়েছে; live provider-এ actual synthetic speech পাঠানো হয়েছে। তাই physical mic end-to-end সফল হয়েছে বলা হচ্ছে না।

OpenStreetMap/Overpass, Open-Meteo এবং Gemini বাহ্যিক provider। Timeout/availability পুরোপুরি নিয়ন্ত্রণ করা যায় না; unavailable তথ্যকে fabricated success হিসেবে দেখানো হয়নি। Nearby data না পাওয়া গেলে এখনও অসম্পূর্ণ তথ্যের label দেখা যেতে পারে।

বিদ্যমান APK-তে microphone permission না থাকলে নতুন APK দরকার হতে পারে; Render deploy দিয়ে installed native permission বদলাবে না। Plain HTTP LAN origin-এ browser microphone নিষিদ্ধ হতে পারে; HTTPS বা localhost ব্যবহার করতে হবে। [Google audio input documentation](https://ai.google.dev/gemini-api/docs/generate-content/audio) অনুযায়ী browser audio format handling review করা হয়েছে।

Deployment owner-এর পরবর্তী নির্দেশে হবে। Single API instance, existing Render config এবং database retention আগে যাচাই করতে হবে। নতুন schema migration নেই; production data copy বা cleanup এই কাজের অংশ নয়।
